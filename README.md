# Repuestos GTA

Landing page moderna para una tienda de repuestos para Chevrolet Corsa, enfocada en conversión y contacto directo por WhatsApp.

## Tecnologías

- Next.js
- React
- TypeScript
- CSS puro

## Scripts

```bash
npm install
npm run dev
```

## Deploy

Se puede desplegar fácilmente en Vercel.

## Personalización

- Cambiar el número de WhatsApp en `app/page.tsx`
- Ajustar productos, modelos y categorías desde el mismo archivo
- Modificar colores y branding en `app/globals.css`
